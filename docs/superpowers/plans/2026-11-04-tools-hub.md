# Tools Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One Tools entry on web and iOS that gathers the existing calculators, so people find `Grow` and friends without knowing they live under Portfolio.

**Architecture:** Navigation only: no backend change, no new maths. Web adds a `/tools` route and a sidebar group; iOS adds `ToolsScreen`, reached from Home and from Portfolio's Planning menu. Each platform has one small catalog that later phases append to.

**Tech Stack:** SvelteKit 3, Svelte 5 runes, vitest (`norviq-web-v2`). SwiftUI, XCTest, Factory (`norviq-ios/financeplan`).

**Spec:** `~/.claude/plans/norviq-tools-market-temperature-cheeky-crystal.md`, Phase 1.

## Global Constraints

- Two repos, two PRs. Work in worktrees from `origin/main`, branch `feat/tools-hub` in each.
- `norviq-ios/financeplan` has 2 untracked directories (`.agents/`, `.claude/`) in its main checkout. Leave them alone.
- No renames. Existing labels and URLs stay exactly as they are on each platform.
- Existing Portfolio nav entries stay in place. Nothing moves.
- Dividends is **not** listed. Its numbers are invented until Phase 4 ships.
- Pro items keep their existing gates. The hub adds no new gate and removes none.
- No new iOS tab.
- No buy, sell, or "good time to" wording.

## Review Focus

1. **Free user opens Rebalancing:** sees the existing Pro gate and a Pro mark on the row, never an error. Pinned in Tasks 2 and 3.
2. **Billing state unknown:** no Pro marks are drawn, matching `featureLockedPredicate` returning null at `src/lib/billing.ts:61`. Pinned in Task 2.
3. **Phone-width web:** the sidebar is hidden, so Tools must be reachable from the bottom tabs' More list. Pinned in Task 1.
4. **Duplicate sidebar group key:** `AppShell.svelte:144` keys groups by `group.tab`, so reusing `'portfolio'` breaks rendering. A new `'tools'` tab is required. Pinned in Task 1.
5. **Portuguese user:** every new string has a pt-PT value. Pinned in Tasks 2 and 3.
